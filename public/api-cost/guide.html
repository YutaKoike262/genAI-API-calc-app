使い方

1. モデルと使用量を選ぶ

会社とモデルを選び、プロンプト、1回の出力トークン数、1日のリクエスト数を入力します。結果には1回あたりの費用と、その回数を30日間使った場合の月額目安を表示します。

入力トークンはASCII約4文字で1トークン、それ以外は約1文字で1トークンという目安です。厳密なトークナイザーによる計算ではありません。

2. 詳細設定で条件を合わせる

システムプロンプト、推論の強さ、その他の入力トークン、キャッシュヒット率、検索回数、バッチ処理を設定できます。キャッシュ書き込みや保存の料金は含みません。バッチ料金が登録されていないモデルではバッチを選択できません。

推論の強さだけでは出力トークン数を自動補正しません。出力の値には思考トークンも含めて設定してください。検索回数は見積もりの想定値で、モデルが実際に呼び出す回数とは異なる場合があります。

各社のAPIやモデルにより、バッチ・検索・推論設定の組み合わせに制限があります。利用時には公式仕様も確認してください。

3. コードを生成する

「コードを生成」を押すと現在の設定からコードを作ります。Python・curl・JSのタブで形式を切り替えられます。設定を変えた場合は「再生成」を押してください。再生成するまでは前の設定のコードが残ります。

APIキーは実行環境の環境変数に設定します。Pythonは anthropic / openai / google-genai、JavaScriptは @anthropic-ai/sdk / openai / @google/genai をインストールして利用します。JavaScriptのコードはNode.jsで実行してください。

出力上限はAPIに合わせて256単位に切り上げ、モデルの最大値で制限します。料金見積もりには入力した出力トークン数を使います。「その他の入力」の文章と、1日のリクエスト数はコードに含まれません。

バッチは非同期です。生成コードはジョブの作成までで、完了の確認と結果の取得は各社の公式ガイドを参照してください。

4. 見積もりを共有する

共有欄で含める項目を確認し、「この見積もりを共有」を押します。スマートフォンでは共有シート、それ以外はURLのコピーを使います。プロンプトは既定では含みません。

「プロンプトも含める」を選ぶと、初期値と異なる1,000文字以内の文章をURLに含めます。それを超える文章は省略されます。URLは暗号化されていないため、機密情報を含めないでください。

受け取ったURLを開くと設定を復元します。不正な値は初期値に戻し、料金はその時点のデータで計算します。料金表の版が変わっていれば案内を表示します。
