トークン数カウンター

APIに渡す文章を貼り付けると、料金メーターと同じ方法で長さを概算します。入力はこのブラウザ内で処理します。

0 文字 ／ 約 0 トークン

計算方法

空白や改行を含め、ASCII文字を4文字で1トークン、それ以外を1文字で1トークンとして換算し、合計を四捨五入します。文字数はUnicodeコードポイント単位です。モデル固有の分割や会話履歴は含まないため、正確な使用量はAPIの応答で確認してください。
